# v1.3.42.1 -- One FilterBar, URL state, header search

`argosVersion` `1.3.42.0` -> `1.3.42.1`. Frontend release (review doc
item 8) shipped inside the v1.3.42.0 drift window: no change to logs,
rollup or bouncer backend. The two backend changes are read-side and
small. Planning: `docs/planning/v1.3.42.1-filterbar-phase0.md`.

## What ships

- **Filters live in the URL.** `useUrlFilters(schema)` +
  `FilterBar` (`frontend/src/hooks`, `frontend/src/components`): every
  list or aggregate page reads its range, filters, tab and page from
  the URL (validated, defaults filled), writes keystrokes with
  `replace` and range / select / tab / page changes with `push`, so a
  link, a reload and the browser's back button reproduce the view.
  Text fields debounce 300 ms; a filter edit goes back to the first
  page. One vocabulary everywhere: `range`, `host_id`, `ip`,
  `country`, `scenario`, `q`, `source`, `status`, `method`, `path`,
  `origin`, `scope`, `type`, `tab`, `page` / `offset`, `limit`.
- **Pages**: Logs (every incoming param honoured, `ip` maps to the
  existing `remote_ip` filter instead of a `q` LIKE over raw, host
  select, debounce, offset reset), Dashboard (one `range` and the
  host in the URL; its links into Logs carry `ip=` / `status=` and
  `range=24h`), Threats (six filters and page in the URL, `q` mapped
  to `search`), Security (`tab`, Banned IPs and Activity filters,
  Scenarios `q`), AppSec (`range` instead of a one-shot `window`),
  Notifications (`tab`, History range / status / event type), Hosts
  (`q` over domain and target group), Backup and Certificates (`tab`).
- **Header search**: paste an IP, CIDR, domain, scenario or text;
  the client classifies it and, on Enter or after 500 ms idle with
  3+ characters (never per keystroke, `AbortController` on edit),
  fans out to existing endpoints: decisions (live), Logs (last 24 h),
  hosts, whitelist, scenarios, WAF alerts (24 h top lists). Every
  section names its window and total and links to the owning page
  with the filter applied. `/` focuses the input, Esc closes.
- **Logs with a deleted host**: a link with a `host_id` that no
  longer exists degrades to "all hosts" with a notice instead of an
  empty list.
- **`GET /api/security/countries`** omits the `cidrs` arrays unless
  `?cidrs=1` (Settings renders counts only): 1,704 bytes for 8
  countries on the demo, about 770 KB before on prod.
- **Range translation in one place**: `lib/filters.ts` maps `range`
  to the dashboard `range`, the AppSec `window` and the `from` ISO
  the logs and deliveries endpoints take, with `npm run test:lib`
  (node:test on the compiled library, no new dependency) covering
  the translations, the URL round-trip and the classifier. v1.3.42.2
  removes the translation in one commit.

## Deploy

Inside the drift window on purpose (operator, 2026-09-26): the
panel restart exercises the rollup recovery from `MAX(hour)` and the
drift check keeps running; recorded in the planning doc when it
happens. `make deploy-prod`, rollback to 1.3.42.0 if not healthy in
60 s. After-smokes: `read-pool.sh` gates 0-2, `dashboard-latency.sh`
